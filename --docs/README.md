# Housing Platform — Business Documentation

## Purpose

This directory contains the authoritative business processes,
business rules, decisions and unresolved questions for the
Housing Platform.

## Documentation principle

Business documentation describes the agreed business behaviour
of the organization. It is independent of the technical
implementation.

## Status

The documentation is progressively developed. A process may be
implemented while later stages remain undefined.
